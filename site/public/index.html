dova

Azure DevOps from the terminal.

Your branch, its PR, its tickets and its pipeline run are one piece of work. Azure keeps them in separate places.

dova puts them on one screen.

02

Nothing to spell out

It reads your git remote. You never type the org, the project or the repo.

Azure CLIaz repos pr create --organization https://dev.azure.com/contoso --project MyProject --repository web --source-branch fix/4821-login --target-branch main --title 'Fix login redirect' --work-items 4821
dova
$ dova link 4821once per branch
$ dova pr create

The same pull request, with the ticket attached.

04

Day to day

  • $ dova pipeline logwhy the run failed: the failed task's log
  • $ dova pr reply 612 4 'Fixed' --resolveanswer a review thread and resolve it
  • $ dova bug 'Login loops' --at src/auth.ts:42a bug in your team's area and sprint, linked to that line
  • $ dova summarize 612catch up on a pull request: tickets, commits, diff
  • ![after](shot.png)in a description or comment, uploads the picture
  • --json  --jq <expr>on every command, for scripts
05

For agents

  • $ dova mcpan MCP server: twelve tools for agents
  • $ dova rpcevery command as JSON-RPC, for other tools
  • $ dova instructionsteaches Copilot, Windsurf, Cursor and Codex to use it
06

Install

  • Windowsdova.maxjay.dev/dova.msi. No admin needed.
  • Ubuntu, Debian, WSLcurl -LO https://dova.maxjay.dev/dova.deb && sudo apt install ./dova.deb
  • From sourcecargo install --git https://github.com/maxjay/dova

Needs git and the Azure CLI. Sign in once with az login.
